# Rotation spec: spells by name, resolved to real ids and levels by tools/make_rotations.py (python3 -I tools/make_rotations.py --dump abilities.log --spec
# data/rotation_spec.txt > data/rotations.txt; the dump comes from tools/abilities_from_db2.py or the core's Bot.Dump.Abilities). Rows are in priority order; buffs are upkeep spells
# cast out of combat when they have run out. Durations are the rank 1 lengths in seconds (a longer real duration only means a recast earlier than needed).
# Conditions: always, target_hp_above N, target_hp_below N, self_hp_below N, self_power_below N, self_power_above N, enemies N, enemies_below N, target_casting, opener N,
# target_strong N, combo N, in_party, no_pet, self_aura_below <spell> <stacks>, self_aura_at_least <spell> <stacks>.
#
# A class has a default block (`class N`) and one block per spec (`class N spec KEY`): a bot plays the block of its spec (the third field of its scenario roster entry,
# race:class:spec; without one the default spec of its class and role, see rotation::DefaultSpec), and a spec with no block plays the class default. The rows come from the
# Wowhead Forever level 30 spec guides (docs/102-wowhead-class-rotations.md in forever-ops) and the rotations the owner pasted; each block says what it could not do.
# Left out on purpose: crowd control, totems that need placing (Searing Totem is cast at the fight's start), a position behind a target (Backstab, Shred from behind), and anything
# that needs a target's target (the snapshot has none: Taunt is cast against two or more enemies). See doc/rotations.md for what was not added and why.
# Rows marked "Forever" are abilities of this fork's client data. A name that the ability dump does not show for the class is dropped with a warning, so a bot never gets a guessed id.
