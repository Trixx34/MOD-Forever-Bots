# Bot names (first name + surname). One row per line, `|` separated, `#` comments, blank lines ignored.
#
#   kind|style|races|classes|sex|weight|text            (kind first or last)
#   pair|style|races|classes|sex|weight|first|last      (a fixed full name that is always used together)
#
#   kind     first = a first name (one word, letters only, 2-12 characters, the same rule as a player's name)
#            last  = a surname (letters, space, apostrophe, hyphen; 2-24 characters)
#            pair  = first and surname that belong together (lore characters, jokes)
#   style    normal = everyday fantasy names, funny = jokes and class puns, lore = names from the game's own world
#   races    * or a comma list of race ids (1 human, 2 orc, 3 dwarf, 4 night elf, 5 undead, 6 tauren, 7 gnome, 8 troll,
#            10 blood elf, 11 draenei); a row with a list is used only for bots of those races
#   classes  * or a comma list of class ids (1 warrior, 2 paladin, 3 hunter, 4 rogue, 5 priest, 7 shaman, 8 mage, 9 warlock, 11 druid)
#   sex      * or m or f
#   weight   1..100, how often the row is drawn next to the other rows of the same kind and style (default 1)
#
# Bots draw: a style by Bot.Names.StyleWeights, then a first name (a `first` row, or the syllable generator the core always had)
# and a surname (a `last` row), or a `pair` row. A name + surname combination is unique on the realm; a taken one is redrawn.
# Rows that break a rule are skipped and logged at start. Adding names: append rows, keep one name per row, no duplicates in a kind.
# Rules kept by tools/check_bot_names.py: no name twice in one kind and style (merge the race lists into one row), no first name
# (or pair first name) that the client NamesReserved/NamesProfanity lists reject (data/name_filters.txt, made by tools/gen_name_filters.py).
# Weights: generic normal rows (race *) are 5, race rows 20, so a race bot gets about 40 percent race names; keep letters balanced.
# See doc/bot-names.md.
